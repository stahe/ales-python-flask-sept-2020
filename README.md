# Introducción a Python 3 y al marco Flask

Este repositorio contiene el sitio web en HTML del curso «Introducción a Python 3 y al marco Flask a través de ejemplos».

🔗 **Consulta la documentación en línea:** [https://stahe.github.io/ales-python-flask-sept-2020/](https://stahe.github.io/ales-python-flask-sept-2020/)

---

## 📝 Contenido

Este proyecto ofrece una lista de scripts en Python que abordan diversos temas:
* Los principios básicos del lenguaje.
* La administración de bases de datos MySQL y PostgreSQL.
* Programación de redes TCP/IP (protocolos HTTP, POP3, IMAP y SMTP).
* Programación web MVC con el marco Flask.
* Arquitecturas de tres capas y programación mediante interfaces.

## 🎯 Público objetivo

Esta colección de ejemplos está dirigida a:
* Desarrolladores que ya tienen experiencia con un lenguaje de script (Perl, PHP, VBScript).
* Desarrolladores acostumbrados a los lenguajes tipados (Java, C#) y que desean descubrir un lenguaje de script orientado a objetos.

> ⚠️ **Nota:** Este documento no es muy adecuado para lectores que nunca han programado o que tienen muy poca experiencia en programación.

## 💡 Filosofía

Este proyecto no es un curso exhaustivo ni una recopilación de «mejores prácticas». El objetivo es ofrecer ejemplos concretos para familiarizarse con el lenguaje Python 3 y con Flask. El código se proporciona tal como está y algunos scripts podrían optimizarse.

Para aprovechar al máximo este contenido, se requiere una **lectura activa**: debes analizar el código, leer los comentarios correspondientes y observar los resultados de salida.
